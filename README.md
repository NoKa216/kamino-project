# Kamino 🌌

**AI Travel Planner**

## Tech Stack 🛠️

- **Mobile:** Expo SDK 54, React Native 0.81 (Managed Workflow)
- **Styling:** NativeWind v4 (Tailwind CSS)
- **AI Engine:** Gemini 3.0 Flash
- **Backend:** Node.js + Express
- **Language:** TypeScript

## Monorepo Structure 📂

This project is organized as a monorepo:

- **`/mobile`**: The Expo React Native frontend application.
- **`/backend`**: The Node.js/Express API server.

## Quick Start 🚀

### 1. Install Dependencies
Run this in the root directory to install dependencies for all workspaces:
```bash
npm install
```

### 2. Run Mobile App
```bash
cd mobile
npx expo start
```

### 3. Run Backend Server
```bash
cd backend
npm run dev
```
